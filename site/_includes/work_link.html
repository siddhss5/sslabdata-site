{%- comment -%} A work's link of one kind, as an anchor, or nothing. `links` is an open map from kind to a *list* of link records. This renders the first record sslabdata can vouch for: - one written in the input (`origin: input`), whatever its verification; or - one of any other origin whose `verification.status` is `verified`. A link sslabdata built itself (`derived`) or took from elsewhere (`sidecar`, `enrichment`, `inferred`, or an origin added later) that nobody has verified is not rendered. An input link that is not verified, whatever its status, is rendered with a visible "unchecked" label. Parameters: `work`, `kind`, `text` (escaped here), and optional `class`, `style` and `blank` (open in a new tab). {%- endcomment -%} {%- assign link = nil -%} {%- assign records = include.work.links[include.kind] -%} {%- for record in records -%} {%- if record.origin == "input" or record.verification.status == "verified" -%} {%- assign link = record -%} {%- break -%} {%- endif -%} {%- endfor -%} {%- if link -%} {{ include.text | escape }} {%- unless link.verification.status == "verified" %} (unchecked){% endunless -%} {%- endif -%}
